# Demo: the finish gate

A transcript of a real run, generated by
[demo.py](../tests/demo.py) in a throwaway project; a test checks that this page
still matches a fresh run. The commands are the ones an agent types, the hook
lines are what Claude Code runs for it, and every output line is SAKO's own.
Paths, dates and times are normalized. It is a scripted run, not a recording of
an agent's judgment.

The story: the agent says it is done before it recorded its work, the gate
refuses and names the fix, the agent fixes the task and its check, closes it with a
receipt, commits, and a fresh session picks up the next task from the files.


## 1. Install

In the project, with no flags. The project has a `CLAUDE.md`, so Claude Code gets the hooks.

```text
$ python3 ../sako/sako.py init
SAKO installed in .sako/ (local). Nothing tracked changed; the folder is listed in .git/info/exclude.
Records: .sako/work/TASKS.md and DONE.md. They are not in Git yet; git clean -x deletes them.
  Keep their history, or share them privately:  uvx sako init --repo [url]
  Commit them with the code:                    uvx sako init --shared
Hooks written: Claude Code (.claude/settings.local.json), chosen from CLAUDE.md. Start a session to begin. Change the client with: uvx sako init --client claude|codex|none.
```

The check is the project's own `check.py`, set in `.sako/config.json` as `"verify_command": ["python3", "check.py"]`.

## 2. The agent says it is done too early

The owner opens the agent in their coding tool. Its hook registers the existing session with SAKO and prints context. The owner asks for a greeting by name, and the agent records the task.


```text
$ python3 .sako/sako.py add "A named visitor gets a personal greeting" --done-when "python3 greeting.py Ada prints Hello, Ada!" --scope greeting.py
T-1: open; recorded locally, not committed
```

The agent edits `greeting.py` but never claims the task, then tries to stop. The gate refuses; exit 2 keeps the session going and shows the agent the message.

```text
$ # Claude Code's Stop hook (demo-agent)
SAKO gate: 1 problem(s) before you stop:
  Recorded: changed this session but covered by no task you claimed or closed: greeting.py
    fix: if this change is T-1 (A named visitor gets a personal greeting), claim it: python3 .sako/sako.py claim T-1 --session demo-agent; otherwise record it: python3 .sako/sako.py add "WHAT CHANGED" --done-when "HOW TO CHECK IT" --scope greeting.py, then claim it; for a change that is not yours or stays unrecorded, say which and why in your reply.
(exit 2)
```

## 3. The agent fixes it

It claims the task and runs the check, which fails: the output lacks the comma and the exclamation mark.

```text
$ python3 .sako/sako.py claim T-1 --session demo-agent
T-1: claimed; recorded locally, not committed. If it pauses or needs working notes, keep them in .sako/work/T-1-a-named-visitor-gets/ (handoff.md for where it stands).
```

```text
$ python3 .sako/sako.py verify
check: FAILED (exit 1) after 0s; no stamp written
expected Hello, Ada! but got Hello Ada
(exit 1)
```

It fixes `greeting.py`, checks again, and closes the task with its evidence.

```text
$ python3 .sako/sako.py verify
greeting check passed
check: PASS in 0s; covered 3 file(s); stamp bcb4b12f530eb1ce -> /work/greeting/.sako/state/stamp.json
```

```text
$ python3 .sako/sako.py close T-1 --session demo-agent --evidence "greeting.py prints Hello, Ada!; check.py passes"
T-1: done; recorded locally, not committed
```

Stopping now is refused again: the work is closed but not committed.

```text
$ # Claude Code's Stop hook (demo-agent)
SAKO gate: 1 problem(s) before you stop:
  Committed: T-1 is closed but its changes are not committed: greeting.py
    fix: git add -- greeting.py, then git commit -m 'T-1: A named visitor gets a personal greeting' when the owner has allowed commits in this session; otherwise ask, or say in your reply: T-1 closed, commit awaiting approval.
(exit 2)
```

```text
$ git add -- greeting.py
```

```text
$ git commit -qm "T-1: A named visitor gets a personal greeting"
```

Before leaving, the agent records the owner's next request. Now the gate is clear.

```text
$ python3 .sako/sako.py add "An empty name gets a clear error" --done-when "python3 greeting.py with no name prints Usage: greeting.py NAME" --scope greeting.py
T-2: open; recorded locally, not committed
```

```text
$ # Claude Code's Stop hook (demo-agent)
(exit 0)
```

```text
$ # Claude Code's SessionEnd hook (demo-agent)
(exit 0)
```

## 4. The receipt

The done record pairs the task's completion condition with the evidence, the closing session, the date and what the check said.

```text
$ tail -1 .sako/work/DONE.md
| T-1 | A named visitor gets a personal greeting | python3 greeting.py Ada prints Hello, Ada! | greeting.py prints Hello, Ada!; check.py passes [sk-0115-7a281dacac30; closed 2026-01-15; check pass 2026-01-15T09:30:00+0000 on bcb4b12f530eb1ce] | `greeting.py` | - |
```
