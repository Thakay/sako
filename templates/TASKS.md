# Tasks

Active local work; `.sako/SAKO.md` is the method. Add work with
`python3 .sako/sako.py add "task" --done-when "observable result" --scope src/`
(`python` on Windows).
`next` picks by priority, then row order. Closing a task moves it to `DONE.md`
with its receipt. Columns you add are kept.
